## 🛠️ Troubleshooting

### Application won't start
- Make sure you have the latest AMD drivers installed.
- Check that your system meets the minimum requirements listed above.
- Try restarting your computer before running the app again.

### Images take a long time to generate
- Close other programs that might be using your graphics card.
- Ensure your computer is plugged into a power outlet (not running on battery).

### Error messages about missing files
- Re-download the application from the link above and try again.
- If you are using antivirus software, it may have blocked the download. Temporarily disable it and re-download.
